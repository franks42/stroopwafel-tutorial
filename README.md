# stroopwafel-tutorial

An interactive tutorial for [stroopwafel](https://github.com/franks42/stroopwafel)
— a tiny Datalog engine for authorization decisions — and the libraries
built on top of it ([signet](https://github.com/franks42/signet) for
crypto, [stroopwafel-pdp](https://github.com/franks42/stroopwafel-pdp)
for the policy-decision-point bridge).

> **Status:** not yet written. This repo currently contains only a
> [HANDOFF.md](HANDOFF.md) with the brief for the person (or AI
> instance) who will actually write the tutorial.

If you're here to **read the tutorial**, come back later.

If you're here to **write the tutorial**, start with
[HANDOFF.md](HANDOFF.md).
